# 剧情导演（SillyTavern Extension）

为 SillyTavern 对话提供聊天级剧情规划、角色演绎约束和生成后审查。它把角色卡、世界书和聊天转为可编辑的剧情档案，在用户发送消息后先调用分析模型规划，再将约束注入正文生成。

## 安装

在 SillyTavern 的“扩展”页面选择“从 Git URL 安装”，填入：

`https://github.com/SAWA-25/sillytavern-narrative-director.git`

安装后打开“剧情导演”，先点击“从当前资料建档”，审阅生成的剧情、关系和角色演绎档案，再启用自动规划。

## 能力

- 维护每条聊天独立的世界规则、能力边界、NPC 议程、时间线与伏笔。
- 将角色卡拆为核心人格、情境化特质、频率/触发条件和反刻板规则，避免关键词放大。
- 要求关系发展具有事件、互动和用户态度基础；限制无依据恋爱、物化和权力失真。
- 默认所有角色同受世界规则约束，阻止主控角色自动获胜和 NPC 工具化。
- 标记 OOC、战力越级、情感跳跃、关键词放大、语气失真、套路桥段等问题；可为消息生成修订候选。

## 模型

默认复用当前已连接的 SillyTavern 模型。也可配置独立的 OpenAI 兼容接口。独立接口由浏览器直接请求，服务端必须允许 SillyTavern 所在来源的 CORS 请求。

## 数据

模型配置保存在本地扩展设置。剧情、关系和角色演绎档案保存在当前聊天的 `chat_metadata`，不同聊天不会互相污染。

## 已知限制

分析质量依赖模型的结构化输出能力。首次版本以 JSON 编辑器呈现剧情档案；后续可扩展为更适合日常编辑的表单与可视化关系图。
